NAS-rclone Privacy Policy

NAS-rclone is a personal, single-user OAuth client used only by its owner with rclone.

What data is accessed

NAS-rclone accesses only the owner's own Google Drive account, to upload, update, list and delete backup files copied from the owner's home NAS.

How data is used

Google user data is used only to store and maintain the owner's own backups. It is not used for any other purpose.

Sharing and storage

No data is sold, shared with or transferred to any third party. Data stays only in the owner's Google Drive and the owner's home NAS. No data is collected by this website.

AI and machine learning

Google user data is not used to develop, improve or train any AI or machine learning models.

Google API Services User Data Policy

NAS-rclone's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact the owner through the GitHub profile at https://github.com/nprhn.
